# SRS v1.0 - Sistema de Gestión de Tareas - Los Marcianos 1D

## 1. Introducción
**Propósito:** Sistema web para gestionar tareas de estudiantes.
**Alcance:** Crear, asignar y dar seguimiento a tareas.
**Equipo:** Los Marcianos

## 2. Descripción General
Usuarios: Estudiante, Profesor, Administrador.

## 3. Requisitos Funcionales
**RF-01 - Inicio de Sesión:** Logueo con correo y contraseña.
**RF-02 - Crear Tarea:** Título, descripción y fecha límite.
**RF-03 - Asignar Tarea:** A uno o varios estudiantes.
**RF-04 - Cambiar Estado:** Pendiente, En Proceso, Completada.
**RF-05 - Generar Reporte:** Reporte de tareas por alumno.

## 4. Requisitos No Funcionales
**RNF-01 Rendimiento:** <2 segundos.
**RNF-02 Seguridad:** Contraseñas encriptadas, token.
**RNF-03 Usabilidad:** Intuitiva, responsive.
**RNF-04 Disponibilidad:** 99% activo.

## 5. Glosario
SRS, RF, RNF, Tarea, Token
